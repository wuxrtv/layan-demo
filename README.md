# LAYAN — Telegram Mini App семейного магазина одежды

Магазин LAYAN («Oilaviy kiyim do'koni») в Telegram + админ-панель. Всё работает на Cloudflare (бесплатный тариф):
сайт — Cloudflare Pages, сервер — Pages Functions, база — D1.

- **Магазин:** https://layan-shop.pages.dev/ — эту ссылку указывать боту в BotFather (кнопка меню)
- **Админка:** https://layan-shop.pages.dev/admin/ — открывается из бота (см. ниже)
- **Cloudflare:** аккаунт магазина Layanliveee@gmail.com, проект `layan-shop`, база D1 `layan`
- Сайт и сервер пересобираются автоматически после каждого `git push` в `main`

Дизайн — «Классика» (выбран клиентом): кремовый фон и золото, как на логотипе, заголовки и цены шрифтом с засечками.

## Что умеет

**Магазин:** каталог с баннером, категориями, поиском, новинками и скидками; карточка товара с галереей, цветами и размерами;
избранное; корзина; оформление (телефон +998, доставка или самовывоз, оплата при получении наличными или картой); RU / UZ.

**Сервер:** проверяет каждый заказ и пересчитывает суммы по ценам из базы (подменить цену с телефона нельзя),
сохраняет заказ и сразу присылает его в Telegram.

**Админка:**
- **Заказы** — список со статусами (новый → подтверждён → выполнен / отменён), телефон, адрес, состав, комментарий; новые подтягиваются сами
- **Товары** — добавить, изменить, удалить, скрыть из магазина, поменять порядок; фото загружаются с телефона (сжимаются автоматически); цвета со своими фото, размеры, скидка, метка «Новинка», тексты RU/UZ
- **Настройки** — стоимость доставки и порог бесплатной, адрес и часы самовывоза, баннер, фото категорий

## Вход в админку — через Telegram

Пароля нет. Админка открывается из бота как Mini App, сервер проверяет подпись Telegram и пускает только тех,
чей Telegram ID есть в списке `ADMIN_TG_IDS`.

### Первая настройка

1. **Бот.** В @BotFather: `/newbot` (или взять существующего) → скопировать токен.
2. **Кнопка магазина.** `/mybots` → бот → **Bot Settings → Menu Button** → `https://layan-shop.pages.dev/`.
3. **Ссылка на админку.** `/newapp` → выбрать бота → указать `https://layan-shop.pages.dev/admin/` и короткое имя `admin`.
   Админка будет открываться по ссылке `t.me/<имя_бота>/admin`.
4. **Секреты в Cloudflare:** Workers & Pages → `layan-shop` → Settings → Variables and Secrets → Add (тип **Secret**):
   - `TG_BOT_TOKEN` — токен бота
   - `ADMIN_TG_IDS` — Telegram ID администраторов через запятую
   - `TG_CHAT_ID` — *необязательно*: ID группы менеджеров. Без него заказы приходят каждому администратору в личку от бота
     (администратор должен хотя бы раз нажать «Start» в боте).
5. После изменения секретов — **Deployments → … → Retry deployment** (или любой `git push`), чтобы они применились.

**Как узнать свой Telegram ID:** открыть админку из бота — если доступа ещё нет, на экране будет написан ваш ID.
Его и нужно добавить в `ADMIN_TG_IDS`.

## Файлы

| Путь | Что внутри |
|---|---|
| `public/` | Сайт: магазин (`index.html`, `app.js`, `styles.css`, `data.js` — тексты RU/UZ) и `admin/` |
| `functions/` | API на Cloudflare Pages Functions: `/api/catalog`, `/api/orders`, `/api/admin/*`, `/img/*` |
| `lib/` | Общий серверный код: проверка данных, Telegram, вход, схема базы, стартовый каталог |
| `wrangler.toml` | Настройки Cloudflare: папка сайта и подключение базы D1 |

База создаётся и заполняется стартовым каталогом **автоматически** при первом запросе — вручную SQL выполнять не нужно.
Стартовые фото — бесплатные фото с [Unsplash](https://unsplash.com/license); в админке их можно заменить на фото клиента.

## Локальный запуск

```bash
npx wrangler@4 pages dev --port 8788 --binding DEV_NO_AUTH=1
```

Откроется магазин на http://localhost:8788 и админка на http://localhost:8788/admin/ с локальной базой.
`DEV_NO_AUTH=1` отключает вход в админку — **только для локального запуска**, в Cloudflare его не задавать.
