# LAYAN — демо Telegram Mini App семейного магазина одежды

Демо-версия мини-приложения для показа клиенту (LAYAN, «Oilaviy kiyim do'koni»). Чистые HTML/CSS/JS, без сборки и без сервера.

**Живая ссылка:** https://layan-shop.pages.dev/ — Cloudflare Pages (аккаунт магазина Layanliveee@gmail.com, проект `layan-shop`). Сайт пересобирается автоматически после каждого `git push` в `main`. Эту ссылку указывать боту в BotFather.

**Дизайн — «Классика»** (выбран клиентом): кремовый фон и золото, как на логотипе, заголовки и цены шрифтом с засечками.

**Что есть:**
- Каталог: баннер, категории «Женщинам / Мужчинам / Детям», скидки, поиск, бейджи «Новинка» и «−20%», избранное
- Карточка товара: галерея фото со свайпом, выбор цвета (у каждого цвета своё фото), выбор размера
- Корзина: количество, удаление, прогресс до бесплатной доставки (от 500 000 сум)
- Оформление: имя, телефон с маской +998, доставка или самовывоз, оплата **только при получении** (наличными или картой через терминал), комментарий
- Экран «Заказ принят» с номером заказа
- Переключатель RU / UZ, цены в сумах
- Интеграция с Telegram: нативная MainButton и BackButton в цветах бренда, вибро-отклик, шапка Telegram в кремовом цвете, имя клиента подставляется из профиля

Вне Telegram (в обычном браузере) приложение тоже работает: вместо нативных кнопок Telegram показываются свои, системная кнопка «Назад» возвращает на предыдущий экран.

> Это демо: заказ никуда не отправляется. Корзина, избранное и контакты хранятся в браузере (ключи `layan:*` в localStorage).

Фото товаров — бесплатные фото с [Unsplash](https://unsplash.com/license) (можно использовать в коммерческих целях). Для боевой версии замените их на фото клиента.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Точка входа |
| `data.js` | **Товары, цены, категории, все тексты RU/UZ.** Правьте здесь |
| `app.js` | Логика экранов, корзина, интеграция с Telegram |
| `styles.css` | Стили (дизайн «Классика») |
| `assets/` | Логотип LAYAN: полный и только каллиграфия (прозрачный фон), плюс оригинал от клиента |

## Как поменять под клиента

- **Название и логотип** — `brand` и `logo` в `data.js`
- **Товары и цены** — массив `products` в `data.js`
- **Фото клиента** — положите фото в папку, например `photos/`, и пропишите путь вместо ID Unsplash: у цвета `photo: 'photos/hoodie-grey.jpg'`, дополнительные фото — в `photos: ['photos/hoodie-2.jpg']`. Лучше вертикальные, пропорция 4:5
- **Баннер** — `banner` в `data.js`, тексты баннера — `bannerKicker`, `bannerTitle`
- **Стоимость доставки** — `delivery` в `data.js`
- **Адрес самовывоза** — `pickupPoint` и `pickupHours` в переводах

## Как показать клиенту в Telegram

Telegram открывает Mini App только по **HTTPS**-ссылке, поэтому папку надо выложить на хостинг.

**1. Выложить сайт (самый быстрый способ — Netlify Drop):**
1. Откройте https://app.netlify.com/drop
2. Перетащите туда папку проекта целиком
3. Получите ссылку вида `https://xxxx.netlify.app`

Подойдёт и GitHub Pages, Vercel, Cloudflare Pages — любой статический хостинг.

**2. Подключить к боту через @BotFather:**
1. `/newbot` — создать бота (или взять существующего)
2. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → вставить ссылку с хостинга и задать название кнопки, например «Магазин»
3. Открыть бота в Telegram и нажать кнопку меню слева от поля ввода — откроется мини-апп

Дополнительно можно сделать прямую ссылку `t.me/имя_бота/shop` через `/newapp` в BotFather.

## Локальный просмотр

Откройте папку через любой статический сервер, например:

```bash
npx serve .
```
